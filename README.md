# Sales Trend Prediction Using Machine Learning

Predicts sales from historical and weather data.

## What it does
- Cleans data (duplicates, missing values, outliers)
- Feature engineering (month, weekend, lag features, rolling average)
- EDA with pandas, NumPy and Matplotlib
- Compares Linear Regression and Decision Tree
- Evaluates with RMSE and R2, plots predicted vs actual

## Tech
Python, pandas, NumPy, scikit-learn, Matplotlib

## How to run
pip install pandas numpy scikit-learn matplotlib
python sales_trend_prediction.py
